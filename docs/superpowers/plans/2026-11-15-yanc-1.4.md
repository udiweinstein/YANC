# YANC 1.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build date in Help, Boot from the Choose volume box (incl. non-ProDOS disks), Esc leaves the KEGS images list, Quit goes to BASIC.SYSTEM when it is there.

**Architecture:** All product code is in `src/yanc.s` (one 65C02 source, existing pattern). Tests run the built binary in the py65 harness (`tests/harness.py`), which gets three small additions. One new test file, `tests/t10.py`, in the `check()` style of `t9.py`.

**Tech Stack:** ca65/ld65 (cc65), Python 3 + py65.

**Spec:** `docs/superpowers/specs/2026-11-15-yanc-1.4-design.md`

## Global Constraints
- 65C02 only; code+data must stay below `$5000` (check `build/yanc.map`), BSS below `$1000`.
- Nothing changes on a real Apple II except what the spec lists; KEGS-only parts stay behind `kegs`.
- Existing tests `t2`–`t9` keep passing. Run: `./build.sh && cd tests && python3 t10.py` (and t2, t8, t9).
- Version string `1.4` in the source header, Help, README.

## Review Focus
1. Choose volume with 14 rows + KEGS item: box must still fit on 24 lines (footer goes on the bottom border, no extra row).
2. `B` on the "KEGS disk images..." row: ignored.
3. `B` on a remapped drive (slot without disk firmware, e.g. S2) or `/RAM` (S3,D2): error box, no jump.
4. Esc at `KEGS:/` when the saved directory is gone (its disk was ejected / replaced by an insert): first volume, no error loop.
5. Quit when the active panel is a KEGS panel: prefix must come from the start directory, never from `KEGS:/`.
Each has a check in t10 (tasks 2–4).

**Interfaces – Produces (harness):**

### Task 2: Choose volume – non-ProDOS rows and `B` = boot
**Files:** Modify `src/yanc.s` (`scanvols`, `k_vol`, `launch`, error table, strings, help), `tests/t10.py`.

**Interfaces – Produces:**
- BSS `vx: .res 14`, `vxn: .res 1`: ON_LINE offsets of entries with length 0 and error `$52` or `$27`; filled by `scanvols`. `vl`/`vn` unchanged. `vn+vxn` capped at 14.
- Box rows: `0..vn-1` volumes, `vn..vn+vxn-1` shown as `" S6,D1  (not a ProDOS disk)"`, then (KEGS) the images row. Footer `" Enter=Select  B=Boot  Esc=Cancel "` printed on the bottom border.
- `text40`: subroutine cut out of `launch` (80-col off … HOME).
- New errors: `ERR_NOTPD=$ED` "Not a ProDOS disk - press B to boot it", `ERR_BOOTD2=$EE` "Only drive 1 of a slot can be booted", `ERR_NOBOOT=$EF` "This drive cannot be booted".
- `B`/`b`: ignore on the KEGS row; drive 2 → `ERR_BOOTD2`; firmware check `$Cs01=$20,$Cs03=$00,$Cs05=$03` else `ERR_NOBOOT`; else close all files, `text40`, `lda $C082`, `ldx #$FF / txs`, `jmp $Cs00`.

- [ ] t10 checks (fail first): row text for a `err=0x52` drive at unit `$50`; Return on it shows the `ERR_NOTPD` text; `B` on S5,D1 (signature poked at `$C501/3/5`) → `e.booted == 0xC500`; `B` on SYSDISK S6,D1 → `0xC600`; `B` on BLANK (unit `$E0`) → "Only drive 1"; `B` on unit `$20` without signature → "cannot be booted"; `B` on KEGS row → box still open; 14 rows + KEGS → footer on screen, row 23 key bar intact.
