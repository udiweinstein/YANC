# YANC 1.4 – design

## Why
Small usability changes asked for by Udi. The main one: start disks that have no
ProDOS on them (games, DOS 3.3) straight from YANC, on a real Apple II and in KEGS.

## Goals
1. **Help (1):** first line shows the build date after the version:
   `YANC v1.4 15-Nov-2026 - Yet Another Norton Commander for the Apple IIc`.
   `build.sh` passes the date to ca65 (`-D`), nothing to edit by hand.
2. **Choose volume (2) – Boot:** Return picks the volume for the panel as today;
   `B` boots the drive on the highlighted row (`JMP $Cs00`).
   - The box now also lists drives whose disk ProDOS can't read (ON_LINE error
     `$52` not ProDOS, `$27` I/O error – copy-protected games), shown as
     `S6,D1  (not a ProDOS disk)`. Return on such a row shows an error; `B` boots it.
   - Only drive 1 of a slot can be booted; `B` on drive 2, or on a slot without
     boot firmware (`$Cs01=$20, $Cs03=$00, $Cs05=$03`), shows an error.
   - A footer line in the box: `Enter=Select  B=Boot  Esc=Cancel`.
3. **KEGS disk images – Esc at the top folder (`KEGS:/`):** the panel goes back to
   the ProDOS directory it showed before the list was opened (path saved per panel).
   If that directory can no longer be read, fall back to the first volume.
4. **Quit (0):** after "Yes", if `BASIC.SYSTEM` is in the directory YANC was
   started from, run it (ends at the `]` prompt; BASIC.SYSTEM runs `STARTUP` if
   there is one). Otherwise ProDOS QUIT as today.

## Non-goals
- Booting a KEGS image straight from the images list (option B in the discussion).
- Booting drive 2.

## Approaches (item 2)
- **A – boot the highlighted drive in Choose volume** (chosen: works on real
  hardware too, and covers non-ProDOS disks).
- B – `B` on an image in the KEGS list: insert into drive 1 and boot. KEGS only.

## Left to the builder
Exact strings, error numbers, where the saved paths live in the `$0800` area,
tests in `tests/` (py65 harness) for each item, README and help text updates.
